# Interface illustrations

These English screenshots show the actual PedalFeel SimHub 0.4.0 interface,
rendered with SimHub's theme in an offscreen UI fixture. The displayed car,
connection state and profile assignment are illustrative; no simulator session
or physical pedal test was running. Control appearance is unchanged from the
released DLL, including the always-available **Stop preview** button.

The settings come from the actual **Original GT3 Balanced** profile factory:
overall strength ×1, upshift pulse 20%, and the other adapted author defaults.
The example Porsche is assigned to that same profile. The 0–35% calibration
shown is the initial configuration, not a measured recommendation for a motor.
