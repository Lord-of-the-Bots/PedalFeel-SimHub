# Interface

| Screen | Controls |
| --- | --- |
| [Profiles](profiles.png) | Select a profile and assign it to the current car. |
| [Create a profile](create-profile.png) | Start from Standard or Original GT3 settings, or copy the selected profile. |
| [Brake effects](brake-effects.png) | Adjust brake feedback and try individual effects. |
| [Throttle effects](throttle-effects.png) | Adjust engine, shifts, limiter and road feedback. |
| [Pedal setup](pedal-calibration.png) | Set power limits by frequency, run 500 ms tests and select pedal channels. |

The 0–35% motor limits shown are the initial settings. Adjust them for your motors and mounting.
