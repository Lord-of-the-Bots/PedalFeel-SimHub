# 0.5.2

- At standstill, only the configured idle effect plays on each pedal. Setting Idle to 0% silences that pedal at rest.
- Stopping clears driving-effect envelopes, including brake pressure, ABS, shifts and road feedback.
- Motor minimum power no longer amplifies idle vibration. Per-frequency maximums and pedal strength still apply.
- A weaker engine background no longer changes the frequency or displayed mode of stronger brake feedback.
- Added explanations in all seven interface languages. Existing profiles, car assignments and calibration settings are retained.
